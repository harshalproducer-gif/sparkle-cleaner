# Sparkle Cleaner

Chrome extension that removes the visible Gemini / Flow sparkle watermark from your own images and videos. Runs 100% locally. MIT licensed.

- `src/` — the extension (load this folder via chrome://extensions → Load unpacked)
- `update.json` — the update feed the extension's *Apply update* button reads
- Releases — zipped builds; each release's SHA-256 is recorded in `update.json`

Update feed URL for the extension's **Updates** panel:

```
https://raw.githubusercontent.com/harshalproducer-gif/sparkle-cleaner/main/update.json
```
